# Game Analytics Dashboard

A local analytics dashboard for manually entered daily game metrics.

## Run
Open `index.html` in a modern browser. No installation, accounts, backend, or external dependencies.

## Data
Data is saved in this browser using localStorage. Demo data is illustrative and is not live production data. Export important data when offered.

## Deploy
Push the files to a public GitHub repository and enable GitHub Pages (Settings → Pages → Deploy from a branch → main / root).
